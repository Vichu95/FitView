# Changelog

## 0.1.0 - 2026-10-28

First public release.

- Weekly planner with drag and drop, single-day view, manual save, hide, duplicate / rename / delete (deleted plans kept in `Plans/_deleted`).
- Front / back body map with 34 muscle regions and weekly volume bands.
- Back-to-back recovery check.
- 145-exercise library (gym + calisthenics) shipped as CSV; built into an editable Excel workbook on first run.
- Add-exercise picker with muscle filter (click the body), role filter and structured entry (amount, unit, per side, load, EMOM).
- Counting settings: EMOM factor and stabiliser credit.
- Exports: PDF (page per day + weekly summary), phone-sized day images, week image.
- Three example plans.
- Windows, macOS and Linux launchers; `--workspace`, `--port`, `--no-browser` options.
